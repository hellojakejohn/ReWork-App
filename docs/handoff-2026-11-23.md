## Things learned this stretch

- Workday rate-limits by IP: probe a few employers at a time, 8 s apart.
- Next's `outputFileTracingIncludes` needs every route that reads files at runtime
  (`/api/fit` for pdfjs, `/api/og/share` for fonts).
- Merging a PR whose branch conflicts: run the full test suite after resolving. A broken
  test file once failed the Vercel build (#80, fixed in #81); production kept the last
  good deploy.
- The read-only Supabase connector in Claude sessions points at another project; use
  `npx tsx` scripts with PrismaClient for ReWork numbers.
