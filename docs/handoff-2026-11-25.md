Read `docs/PROJECT.md`, then `STATE.md` ("Free-tool leads"), then this.

## What shipped (PR on branch `claude/email-capture-check-fit-eea329`)

- **Optional email card under the free results.** /check: "Want the ghost-job red flags
  checklist + a heads-up when we add new checks? Drop your email." /fit: "Want your missing
  keywords emailed + tips to close the gap? Drop your email." Button "Send it", line "No
  spam. One-click unsubscribe.", an x to dismiss. Only after a result renders, under it,
  never a modal, nothing pre-checked. Dismissed or sent stays hidden in that browser.
- **`POST /api/leads`**: zod check, the same IP speed bump as /check and /fit, a hidden
  honeypot field, no account. Always answers `{ ok: true }` for a valid email, new or not.
- **`leads` table**: email (lowercased), source (check or fit), ref (the `?ref=`/utm tag
  from the signup-source cookie, else "direct"), landing path, consent version, created,
  unsubscribed. One row per email per tool. Never the job, link or resume text.
- **One email per new lead**, behind a flag (off by default). /check gets the ghost-job and
  scam checklist. /fit gets the missing keywords plus "close the gap" tips from the cached
  skill plans (no AI call, no cost). Each has a one-click unsubscribe that sets
  `unsubscribedAt`.
- **Tracking**: `lead_captured` { source, ref }. Confirmed `job_check_public` and
  `fit_check_public` fire on the server after a result (not on page load);
  `job_check_public` also fires on failed checks with `ok: false`, so the admin count
  uses `ok: true` only.
- **/admin Analytics**: "Completed: first 100" (job checks, fit checks, tailors, and all
  three added up; last 7 days / all time) and an "Emails from /check and /fit" table by tool
  and ref, with unsubscribes.

## How to read the new admin numbers

- **Completed: first 100**: big number = last 7 days, small = all time. "All three" is a
  count of results, not people (/check and /fit have no account, so one person running
  three checks counts three). Your own test runs count too.
- **Emails from /check and /fit**: one row per tool and ref tag. "direct" = no tagged link
  and no referring site. Divide leads by completed checks or fits for the capture rate.
